## 실행 방법

Python 3.10 이상이 필요하며, 추가 패키지 설치 없이 실행할 수 있습니다.

```powershell
git clone https://github.com/kjhmoon/RobotAlgorithm-GPS-Localization-team16.git
cd RobotAlgorithm-GPS-Localization-team16
python src/check_environment.py
```

환경 확인 코드는 Python 버전과 1주차 필수 파일·폴더의 존재를 검사합니다.
